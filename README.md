
# AI Film Studio

AI Film Studio is a mobile-friendly workspace for planning and organizing AI-assisted animated film and anime projects.

## Features

- Create and organize film projects.
- Plan stories, seasons, episodes, scenes, and dialogue.
- Manage character profiles and reference images.
- Organize visual assets and production notes.
- Plan audio, sound effects, and music.
- Review scenes and track production progress.
- Organize short clips for manual assembly.
- Support Arabic and English interfaces.

## Important Notes

- Actual video generation requires a compatible generation provider and backend integration.
- Supabase must be configured before database features can work.
- Free-tier limits depend on the selected service.
- The application must not make purchases or enable paid services without explicit user approval.
- Never publish secret API keys or Supabase service-role keys in frontend code.
- Video downloads should happen only when requested by the user.

## Project Status

This project is under development. Features must be tested and connected to their required services before being considered operational.
