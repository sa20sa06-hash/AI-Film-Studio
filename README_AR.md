
# استوديو صناعة الأفلام بالذكاء الاصطناعي — AI Film Studio

تطبيق لتنظيم وإدارة مشاريع الأفلام والأنمي بمساعدة الذكاء الاصطناعي، مع واجهة مناسبة للهواتف.

## المميزات

- إنشاء المشاريع وتنظيمها وحفظ تفاصيلها.
- تخطيط القصص والمواسم والحلقات والمشاهد والحوارات.
- إنشاء ملفات للشخصيات وتنظيم الصور المرجعية.
- تنظيم الخلفيات والصور والملفات والموارد.
- تخطيط الأصوات والمؤثرات والموسيقى.
- مراجعة المشاهد ومتابعة تقدم الإنتاج.
- تنظيم المقاطع القصيرة وتجهيزها للتجميع اليدوي.
- دعم الواجهتين العربية والإنجليزية.

## متطلبات التشغيل

- إعداد Supabase وربطه بالتطبيق لاستخدام ميزات قاعدة البيانات.
- ربط خدمة متوافقة لتوليد الفيديو عند الحاجة.
- نشر الوظائف الخلفية المطلوبة في بيئتها الصحيحة.
- اختبار الميزات قبل اعتبارها جاهزة للاستخدام.

## سياسة الاستخدام والتكاليف

- استخدام الخدمات المجانية أولاً.
- عدم شراء أي خدمة أو تفعيل خطة مدفوعة دون موافقة صريحة من المستخدم.
- التوقف عند انتهاء الحصة المجانية بدلاً من الانتقال التلقائي إلى الدفع.
- عدم وضع مفاتيح API السرية أو مفتاح Supabase من نوع service_role في ملفات الواجهة العامة.
- تنزيل الفيديو يدوياً فقط عندما يطلب المستخدم ذلك.

## حالة المشروع

المشروع قيد التطوير. رفع الملفات إلى GitHub لا يعني أن جميع الميزات أصبحت تعمل؛ إذ تحتاج بعض الميزات إلى إعداد الخدمات الخلفية وربطها واختبارها.
